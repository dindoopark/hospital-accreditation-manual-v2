홈 화면에 추가하기

휴대폰 홈 화면에 아이콘으로 두면 앱처럼 바로 열리고, 한 번 본 내용은 인터넷이 끊겨도 볼 수 있습니다.

매뉴얼 주소

주소를 불러오는 중…

지금은 USB·PC에 있는 파일을 직접 열었기 때문에 홈 화면 추가가 되지 않습니다. 인터넷 주소로 접속한 뒤 아래 방법을 따라 주세요.

자주 묻는 것

데이터가 많이 드나요?
처음 열 때 본문(약 1.3MB)을 받고, 슬라이드 그림은 열어 본 것만 저장합니다. 전체 슬라이드를 다 열면 약 25MB 정도입니다.
인터넷이 안 되는 곳에서도 되나요?
한 번 연 화면은 그대로 열립니다. 아직 열어 보지 않은 슬라이드 그림은 인터넷이 있어야 보입니다.
내용이 바뀌면 어떻게 되나요?
앱을 열면 자동으로 확인해서, 새 내용이 있으면 화면 아래에 새로고침 안내가 뜹니다.
아이콘을 지우려면?
홈 화면에서 아이콘을 길게 눌러 삭제하면 됩니다. 저장된 내용도 함께 지워집니다.
