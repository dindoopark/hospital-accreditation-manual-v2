부록 5. 의료기관 종사자의 노출 후 예방적 투약이 필요한 질환

| 질환 | 예방조치 | 적응증 | 금기사항 | 특이사항 |
|---|---|---|---|---|
| 디프테리아 | -(검사) 백신접종 여부와 상관 없이 비강과 인두부위검체에 대한 균배양검사 실시, 검사를 받고 7일간 발병여부 감시<br>-(노출 후 예방요법) 균배양검사 이후, 백신접종 유무에 상관없이 Penicillin, 1.2 mU IM 1회; Erythromycin (1g/day) PO 7일-10일간 투여 | 디프테리아로 확인된 사람이나 보균자의 구강분비물에 노출된 직원 | | -(예방접종) 불완전한 예방접종력을 가진 사람의 경우, 연령별로 정해진 접종 실시<br>-증상발생 모니터링 |
| A형 간염 | 노출 후 2주 이내 deltoid나 gluteal에 0.02 ml/kg IG를 1회 근육주사 | 적절한 개인보호구 착용 없이 환자와 접촉한 의료진 | IgA 결핍증; MMR 접종 후 2주 이내 또는 수두 백신 접종 후 3주 이내에는 투여하지 않는다 | -(예방접종) 노출 후 예방을 위해 2차 접종 불필요, 평생면역 획득을 위해 1차 접종 후 6개월 후 2차 접종 |
| 수막알균 질환 | Rifampin, 600mg PO로 매 12시간마다 2일 투여;<br>Ceftriaxone 250mg 1회 근육주사;<br>Ciprofloxacin 500mg 1회 경구투여 | 감염된 환자의 호흡기 분비물에 적절한 주의지침 없이 직접 접촉한 직원 (예: 구강 대 구강 인공호흡, 기관내 삽관, 기관내 삽관 관리, 구인두 검진) | 임신 중 Rifampin과 ciprofloxacin은 사용하지 않는다 | |
| 백일해 | 노출 후 14일 동안 Erythromycin, 500 mg qid PO 또는 Trimethoprim-sulfamethoxazole 1정 bid PO 복용 | -환자와 1m 이내 대면접촉<br>환자의 구강분비물에 직접 접촉<br>-구강 대 구강 (좌측 면 하단에서 잘림, 우측 면으로 이어짐) | | -(예방접종) 불완전한 예방접종력을 가진 사람의 경우, 연령별로 정해진 접종 (우측 면으로 이어짐) |

(우측 면 — 같은 표가 이어짐)

| 질환 | 예방조치 | 적응증 | 금기사항 | 특이사항 |
|---|---|---|---|---|
| (앞 행에서 이어짐) | | 인공호흡, 기관 내 삽관, 기관지 흡인 환자와 1시간 이상 한정된 같은 공간에 가까이 머무른 경우 | | 실시 |
| 광견병 | 예방접종을 맞은 적이 없는 사람은 HRIG 20IU/kg 접종하되 반은 상처 주위에 접종한다. 그리고 HDCV 또는 RVA 백신을 1.0ml deltoid 부위에 0, 3, 7, 14, 28일 근육주사 한다 | 광견병이 있는 사람이나 동물에게 물리거나 본인의 상처 또는 점막에 환자의 타액이나 감염성 물질(예: 뇌조직)이 닿아 오염된 경우 | | 이전에 예방접종을 맞은 사람은 HDCV 또는 RVA 백신을 0, 3일에 1.0 ml 근육주사하고 HRIG는 필요치 않다. |
| Varicella zoster virus | VZIG를 근육주사 하되, 투여량은 체중 고려하여 사례별 확인 | Varicella에 감수성이 있는 사람이나 감염성 있는 사람에게 노출된 직원 중 특히 감염 시 합병증의 위험이 큰 사람, 즉 임신 또는 면역저하상태의 직원에게 접종한다 | | VZIG를 접종하기 전 혈청검사를 먼저 해 보는 것이 좋다. VZIG로 노출 후에 수두를 예방할 수 있으나 나중에 백신을 접종하도록 한다. |
| 옴 | 전신에 오메크린 크림 도포 후 12시간 정도 지속. | 감염환자와 직접 피부 대 피부의 접촉을 한 경우 | 임부/수유부/면역저하자, 약에 과민증 환자 | 분리한 의복, 침구류 세탁, 소독이 필요하다. |

(우측 면에서 앞 행(백일해)의 이어지는 글자와 광견병 행 사이에는 가로 선이 보이지 않음)
