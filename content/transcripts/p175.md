**6. 의료기기 회수**
가. 병원에 자산으로 등재된 의료기기 중, 안전상의 이유 등으로 의료기기 관련 행정기관 또는 공급업체에 의해 사용이 철회된 의료기기에 대해 적용한다.
나. "회수"라 함은 의료기기 판매 임대업자 (이하 "업체" 라고 한다) 로부터 구매, 임대한 의료기기 중 사용이 철회된 의료기기를 반환하는 것을 말한다.
다. 부적합 의료기기에 대한 회수 절차
  1) 사용부서는 업체로부터 회수 공문을 받으면 접수하고 물류자산팀과 의공팀으로 전달한다.
  2) 의공팀은 장비 보유 여부와 수량을 확인하여 사용 부서와 교체 계획을 검토하고 시행한다.
  3) 물류자산팀은 업체의 회수 계획에 따라 경영진에게 결과를 보고하고 의료기기를 사용부서로부터 회수하여 업체로 반환한다.
  4) 의공팀은 회수 조치가 완료 된 후 "회수 의료기기 관리 기록부"를 작성하고 원내 공지한다.
라. 의료기기 회수 결과 보고
   의료기기 회수에 대한 결과를 연 1 회 이상 정기적으로 기자재심의위원회(의료기기 분야) 에서 검토하고 경영진에게 보고한다.

**7. 의료기기 오작동 및 안전사고 관리**
가. 의료기기 사용자 교육
  1) 기존 보유 장비 교육
     의료기기 사용법, 취급 주의사항, 일상점검, 문제발생시 대처/처리방법 등에 관한 의료기기 안전관리 교육을 사이버교육으로 연 1 회 실시한다.
  2) 신규장비 도입 시 의료기기 교육
     의료기기 공급자는 의료기기 설치 및 검수 시 의료기기 사용방법, 취급 시 주의사항, 일상점검 방법, 문제 발생 시 대처방법 등을 사용자가 충분히 숙지할 때까지 사용부서에 교육을 실시한다.
나. 의료기기 문제 발생(오작동, 안전사고 등)시 대처/처리 방법
  1) 환자로부터 접속된 의료기기를 분리한다.

  2) 환자의 안전을 확인한다.

[그림: 고장수리절차 흐름도]
- 사용부서 고장신고 ( 의공팀 T1354 신고 ) → 의공팀 접수 → 의공팀 고장사항 확인 → (판단) 수리 가능여부
  - 수리 가능여부 NO → 기술검토서 작성 → 사용부서 전달
  - 수리 가능여부 YES → (판단) 자체수리
    - 자체수리 YES → (판단) 부품사용
      - 부품사용 YES → 수리용 부품 구매 (구매 요구) → 부품 사용 수리 → 수리 완료
      - 부품사용 NO → 기기 수리 → 수리 완료
    - 자체수리 NO → 외주 수리 → (판단) 비용 발생
      - 비용 발생 YES → 수리용 부품 구매 (구매 요구) → 부품 사용 수리 → 수리 완료
      - 비용 발생 NO → 기기 수리 → 수리 완료

**8. 의료기기 부작용 발생 시 보고 및 조치**
가. 원내 보고
  1) 의료기기를 사용하는 도중에 인체에 심각한 부작용이 발생하였거나 발생할 우려가 있음을 인지한 경우 의료기기 사용자는 의료기기 사용을 중지하고 의공팀에 신고한다.
  2) 환자에게 위해가 있는 경우는 '환자안전사고보고및처리절차지침' 에 따라 보고한다.
  3) 의료기기에 관한 사항은 기자재심의위원회 (의료기기 분야)를 통해 경영진에 보고한다.
