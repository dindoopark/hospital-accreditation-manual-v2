## 조사항목/방법

| | 조사항목 |
|---|---|
| 1 | 정확한 환자 확인에 대한 규정이 있다 |
| 2 | **의약품 투여** 전에 환자를 정확하게 확인한다 |
| 3 | **수혈** 전에 환자를 정확하게 확인한다 |
| 4 | 검사 시행 전에 환자를 정확하게 확인한다 |
| 5 | 진료, **처치 및 시술** 전에 환자를 정확하게 확인한다 |

(표 안의 굵은 글씨는 원본에서 빨간색)

1. 조사위원이 환자확인 관찰 (조사위원이 멀리서 관찰 가능)
2. 환자확인 방법에 대해 질문을 할 수 있음

※ 환자의 이름을 개방형으로 확인하고 환자의 등록번호를 폐쇄형으로 확인한다.

[그림: 3단계 흐름도 — ❶ → ❷ → ❸ (노란 바탕 상자 3개가 화살표로 연결)]

❶ 이름 개방형 확인
**“성함이 어떻게 되시나요?”** (파란색)

→

❷ 환자확인팔찌를 PDA 로 찍음
**“등록번호를 확인하겠습니다.”** (파란색)

→

❸ 라벨과 일치여부 확인
투약, 수혈, 검체 라벨의 등록번호 등
환자정보와 일치하는지 반드시 확인

[그림: 사진 — 환자 손목의 환자확인팔찌를 PDA로 스캔하는 모습(타원형 사진)]

[그림: 환자확인팔찌 예시(회색 상자) — "12345678 / 055병동 / 김분당 / 여/75세 / 46년 10월 15일"]

[그림: PDA 화면캡처 — 상단 상태바 "오후 1:45", 메뉴 "투약 채혈 수혈", 우측 "초기화". 환자정보 "김분당 / (12345678) F/75세 / 461015 / B+ / 신경외과 055/01/01", "감염정보:". 등록번호 "(12345678)"과 생년월일 "461015" 부분에 빨간 네모 표시]
