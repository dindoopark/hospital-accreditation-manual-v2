## 음압격리병실/보호격리실

| | 음압격리병실 | 보호격리실(양압) |
|---|---|---|
| 시설팀 모니터링방법 | 월 2회 양압 유지상황 점검 측정 후 기록지를 해당 부서장 전달 (두 열 병합) | |
| 해당 부서 모니터링 방법 | 격리실 사용 시작 시 점검 – 사용기간 매일 점검, 격리 미시행 시 1회/월 | 면역저하환자 입실 시 격리실 사용 시작 때 점검 – 사용기간 동안 매일 점검 |
| 문제 발생 시 관리방법 | 1) 방문과 창문 밀폐상태 확인하고 30분후 다시 점검 2) 문제 상황에 따라 관련부서 연락 (두 열 병합) | |
