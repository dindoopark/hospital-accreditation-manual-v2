원내 질관리지침 확인방법

## 1) BESTCare – 메뉴– '지침' 검색

[그림: BESTCare Menu 검색 화면캡처(어두운 배경) — 검색창에 "지침" 입력, 검색 결과 중 맨 아래 "SNUBH통합지침" 항목이 빨간 사각 테두리로 강조됨]
- 상단: Menu / 기본 / 텍스트 / 카테고리 표시(체크) / 검색창 "지침" / 검색 버튼
- 지침 검색결과 5 / 닫기 버튼
- 환경설정 > 처방관련설정 : 표준지침관리
- 도움말 > 진료 업무매뉴얼 : 진료지침(★ 즐겨찾기 표시), 임상전담간호사 업무지침
- 간호 / 도움말 > 간호업무매뉴얼 : 신입간호사교육 지침서(★ 즐겨찾기 표시)
- **SNUBH통합지침 / SNUBH 통합지침 : SNUBH 통합지침(★ 즐겨찾기 표시)** ← 빨간 테두리 강조

## 2) BESTCare 우측 상단

[그림: BESTCare 우측 상단 드롭다운 메뉴 화면캡처 — 선택상자에 "SNUBH통합지침" 이 선택되어 있고, 목록 맨 아래 "SNUBH통합지침" 항목이 선택(하이라이트)됨]
드롭다운 목록(보이는 순서):

- SAFE 안전보고
- 약제
- 의무기록
- 환자이송
- 통합통계
- ERP
- 부서행정
- 의학연구(MSRI)
- CDW 지표관리
- SMS 보내기
- CRM
- **SNUBH통합지침**

[그림: "SNUBH 통합지침" 창 화면캡처 — 상단 검색창과 조회 버튼, 아래 폴더 트리]
- 창 제목: SNUBH 통합지침
- 검색창 문구: 키워드 검색 예) 환자확인, 낙상 등
- 버튼: 조회 / (새로고침 아이콘)
- 폴더: 질 관리 지침
- 폴더: 감염관리지침
