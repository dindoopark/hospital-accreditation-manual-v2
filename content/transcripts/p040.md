# p040 | 1.4 낙상 예방활동

- redBorder: true

**낙상매트 사용 금지** (파란색, 우측 상단)

- 낙상고위험환자 예방활동
  1. 직원간 정보 공유 (낙상 아이콘, 환자확인팔찌에 '낙상주의' 스티커 부착, 협조 어려운 환자 이송시 이송요원에게 주의사항 인계)
  2. **낙상고위험환자 낙상 예방교육** (밑줄) 시행 → 교육 시행 후 환자 또는 보호자에게 서명 받음
  3. 필요시 의학적, 약학적 중재 (낙상 유발 의약품의 용량 또는 투여 시간 조절을 검토, 협의 진료 및 재활치료)
  4. 환경·시설 관리 (바닥이나 복도에 미끄러운 용액이나 물 등이 방치되지 않도록 발견 즉시 조치, 야간에는 적절한 조명 유지되도록 관리, 침대 난간 올려진 상태로 유지 등)

※ 낙상유발의약품

[그림: 약 봉투(투약 라벨) 사진 — "김분당 / 012(01) / 12345678 / 69년 03월 05일 / (정구) 10-21 / Rivotril 0.5mg (Clonazepam) ● 0.5tab [P.O] bid p / 08:00/, 19:00/ bid pc", 우측 하단 "[낙상주의]" 문구에 빨간 네모 강조]

[그림: EMR 아이콘 — PRN 물방울 모양 아이콘, 라벨 "PRN가능약물/Dr.확인후/낙상유발의약품목록"]

[그림: EMR "환자평가" 그래프 화면캡처 — 낙상 점수 추이 그래프, 좌측 범례(점수 구간별 위험군 구분, 글자 [판독불가]), 그래프 상단의 노란색 점을 화살표로 가리키며 "20점 노란색 점으로 표기" 설명 상자]

[그림: EMR 환자 목록 일부 화면캡처 — 열 제목 "욕창", "낙상", 값 "22", "Y"(낙상 열에 Y 표시)]
