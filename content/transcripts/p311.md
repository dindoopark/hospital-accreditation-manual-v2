# p311 | 5.4 진정치료
- kind: content
- redBorder: false

## 조사항목/방법

| | 조사항목 |
|---|---|
| 1 | 진정치료에 대한 규정이 있다. |
| 2 | 진정치료를 수행하는 직원은 적격한 자격이 있다. |
| 3 | 진정치료 전 평가를 수행한다. |
| 4 | 진정치료 환자를 모니터링하고 기록한다. |
| 5 | 응급상황 발생 시 대처방안에 따라 수행한다. |
| 6 | 진정 회복 후 퇴실 기준에 따라 적격한 자가 퇴실을 결정한다. |

1. 조사위원이 질문
2. 의무기록 확인

- 진정치료 교육 + CPR 교육 + 간호사 보수교육 이수 : 진정치료, CPR은 1회/2년으로 내가 교육받았던 해당년도 숙지
- 진정치료 대상 의약품 : 포크랄, 미다졸람, 케타민, 아티반, 프리세덱스, 에토미데이트

| | |
|---|---|
| 진정 **전** | 투약 전 환자상태를 확인하는 단계 |
| 진정 **중** | 투약 후 원하는 진정 깊이에 다다른 시점부터 검사 종료까지 |
| 진정 **후** | 검사 종료 후 환자가 깨어날 때까지 |
| 진정 **종료** | 완전히 깨어남을 확인한 상태 |

(표 주: 좌측 열은 연두색 배경, "전/중/후/종료"는 빨간 글씨)
