## 공기주의 질환 격리 관련 안내문

| 항목 | 내용 |
|---|---|
| 병실 사용 | 음압격리병실에 입실합니다.<br>(단, 음압격리병실이 없는 경우 격리병실에서 격리 후 이실) |
| 격리 해제 | 관련검사 시행 후 임상증상 등 종합적으로 판단하여 결정합니다. |
| 손위생 | 격리실로 들어가기 전, 환자 접촉 전/후, 개인보호구를 벗은 후, 격리실에서 나오기 전 손위생을 시행합니다.<br>(알코올젤 또는 물과 비누를 이용한 방법 모두 가능하지만, 눈에 보이는 오염이 있을 경우 물과 비누를 이용하여 손씻기 시행) |
| 개인보호구 | -N95마스크를 착용하며, 피부병변이 있는 경우에는 가운과 장갑도 착용합니다.<br>-수두/홍역/파종성 대상포진의 경우 일반마스크 착용, 면역력이 없는 경우 출입을 제한합니다. |
| 환기 및 환경관리 | -환자 퇴실 후 병실 환기를 시행하게 됩니다.<br>-입실동안 청소사원이 환경관리를 시행합니다. |
| 세탁물 관리 | 환자가 사용한 환의, 시트, 이불 등은 병실 안에 있는 **주황색 세탁물 수집자루에 분리배출** 합니다. |
| 폐기물 관리 | 환자가 사용한 알코올 솜, 마스크, 장갑, 가운 등의 폐기물은 격리실 안에 비치된 **붉은도형이 그려진 격리의료폐기물박스**에 폐기합니다. |
| 환자 이동 | -격리실에서 나올 때 환자는 반드시 일반마스크 착용합니다.<br>-검사, 시술 등 반드시 필요한 경우를 제외하고 이동을 제한하며 환자 이동 시 반드시 간호사실에 알리고 안내에 따라주시기 바랍니다. |
| 면회객 관리 | -감염 예방을 위해 방문객은 제한하며, 의료진(의사, 간호사)의 지시에 따라 주의사항을 준수해야 합니다.<br>-기타 궁금하신 사항은 간호사실에 문의해 주시기 바랍니다. |

¶ 환자 상태에 따라 의료진 판단 하에 다인실 내에서 물리적인 방법으로 격리할 수 있습니다.
  다인실 내 격리중인 경우 세탁물과 폐기물 관리는 일반환자와 동일하게 처리합니다.

## 다제내성균 격리 관련 안내문

| 항목 | 내용 |
|---|---|
| 병실 사용 | -환자와 주위환경을 보호하기 위해 격리실에 입실합니다.<br>-같은 균이 분리된 다른 환자와 함께 격리실을 사용할 수 있습니다. |
| 격리 해제 | -분리검체 검사(일부 보균검사 동시 시행)를 환자 상태에 따라 2일~1주일 간격으로 시행해서 연속 3회 균이 나오지 않을 경우 격리를 해제 할 수 있습니다.<br>-증상 호전 시 임상적 판단 하에 격리 해제 할 수 있습니다.<br>-외래의 경우 외래 일정을 고려하여 검사 간격이 길어질 수 있습니다. |
| 손위생 | 격리실로 들어가기 전, 환자 접촉 전/후, 개인보호구를 벗은 후, 격리실에서 나오기 전 손위생을 시행합니다.<br>(알코올젤 또는 물과 비누를 이용한 방법 모두 가능하지만, 눈에 보이는 오염이 있거나 클로스트리디오이데스 디피실레의 경우 물과 비누를 이용하여 손씻기 시행) |
| 개인보호구 | **-환자 접촉시 장갑과 긴팔 가운을 착용합니다.**<br>특히 대소변 치우기, 체위변경, 침상목욕 등 환자와 직접 닿는 면이 클 경우 반드시 착용합니다.<br>**-병실을 나오기 전, 병실 안에서 가운과 장갑을 제거하고 손위생을 합니다.** |
| 환경관리 | 격리병실 청소전담자가 정기적으로 청소를 실시합니다. |
| 세탁물 관리 | 환자가 사용한 환의, 시트, 이불 등은 병실 안에 있는 **주황색 세탁물 수집자루에 분리배출** 합니다. |
| 폐기물 관리 | 환자가 사용한 알코올 솜, 마스크, 장갑, 가운 등의 폐기물은 격리실 안에 비치된 **붉은도형이 그려진 격리의료폐기물박스**에 폐기합니다. |
| 환자 이동 | -격리실에서 나올 때 환자/보호자는 반드시 손을 씻습니다.<br>-검사, 시술 등 반드시 필요한 경우를 제외하고 이동을 제한하며 환자 이동 시 반드시 간호사실에 알리고 안내에 따라주시기 바랍니다. |
| 면회객 관리 | -감염 예방을 위해 방문객은 제한하며, 의료진(의사, 간호사)의 지시에 따라 주의사항을 준수해야 합니다.<br>-기타 궁금하신 사항은 간호사실에 문의해 주시기 바랍니다. |
