## 신속대응체계 : 호출방법, 호출기준

- 대상 : 모든 진료과 병동 및 검사실(18세 이상, 소아청소년과 제외)
- 운영 시간 : 365일, 24시간 운영
- 활성화 방법
  1) 호출 [1동] ☎ 4000, [2동] ☎ 5000
  2) 원내 조기경보시스템

[그림: 신속대응체계 활성화 흐름도(세로 순서도). 환자상태악화 → V/S 측정 → 임상관찰기록지 → BESTboard팝업 → Screening → SAFER RN검진 → SAFER Dr검진 → 해제. 별도 경로로 V/S 측정 → Call → SAFER RN검진 으로 연결되는 화살표가 있음]

[그림: 호출기준/스크리닝 기준 박스(파란 테두리)]

**호출기준**
- ◆ Conscious state : 갑작스런 의식변화
- ◆ Airway : 천명 혹은 호흡부속근 사용
- ◆ Breathing : RR<10, RR>30, SpO2<90
- ◆ Circulation : HR<50, HR>140, SBP<90
- ◆ Anyconcern

**조기경보 시스템 스크리닝 기준**

| (좌) | (우) |
|---|---|
| ◆ SBP < 90 | ◆ pH < 7.25 |
| ◆ HR < 50, > 140 | ◆ PaCO2 > 50 |
| ◆ RR <10, > 30 | ◆ PaO2 < 55 |
| ◆ BT > 39, < 36 | ◆ Lactic > 4 |
| ◆ SpO2 < 90 | ◆ TCO2 < 15 |

※ 소아 신속대응체계 (PRRS; Pediatric Rapid Response System)
- 18세 미만 또는 소아청소년과 일반병동 입원 환자
- PEWS(Pediatric Early Warning Score) 기반의 스크리닝을 통해 실시간으로 4점 이상의 고위험 환자 자동 선별되어 이상징후 감지 시 소아 신속대응 담당 의사에게 알람 전송 → 적절한 중재 결정
