# p024 | 1.2 의료진간 정확한 의사소통
- kind: content
- redBorder: true

[중요 Tip]

◆ Dr.확인후 처방 수행 시 간호기록 작성 방법

1) 일반적인 방법
통증 호소 등으로 **의사에게 확인 받고 투약하는 경우 확인 받은 의사명**으로 기록
특히 **당직 시간** 등 처방의와 확인 받은 의사가 다른 경우 **확인 받은 의사명으로 수정 필요**

2) 의사에게 확인 받지 않고 프로토콜에 따라 간호사가 투약을 수행하는 경우 (Alberti's regimen)
프로토콜에 따라 수행하는 경우, '처방의' 로 의사명 수정 기록
: Dr.확인후 order에 의해 투약함 (약품명: Humalog 용량: 2u, 투약경로: SC, 의사명: **처방의**)
또는 **[preNote]에 치료계획에 대한 내용 명시+** 오더에 따른 투약함

[그림: 간호기록 예시 화면캡처] target BP보다 높게 측정되어 오더에 따른 투약함 (용량 : nicardipine 1mg, 투약 경로 : IVS).
