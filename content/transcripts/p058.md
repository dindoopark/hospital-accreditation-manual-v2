## 조사항목/방법

| | 조사항목 |
|---|---|
| 1 | 환자안전사고 관리 절차가 있다 |
| 2 | 직원은 환자안전사고의 정의를 알고 발생 시 보고한다 |
| 3 | 보고된 환자안전사고를 분석한다 |
| 4 | 환자안전사고 분석결과에 따라 개선활동을 수행한다 |
| 5 | 환자안전사고 분석결과를 경영진에게 보고하고 관련 직원과 공유한다 |
| (번호 표시 없음) | 적신호사건 발생 시 환자와 보호자에게 관련 정보를 제공한다 |
| (번호 표시 없음) | 환자안전 주의경보 발령 시 관련 직원과 공유한다 |

1. 조사위원이 질문
2. 관련 자료 확인

- 환자안전사고 : 환자에게 보건의료서비스를 제공하는 과정에서 환자안전에 위해가 발생하거나 발생할 우려가 있는 사고

[그림: 환자안전사고 위해정도(Level) 분류와 보고 구분 도식. 왼쪽부터 색 막대 4칸과 그 사이의 판단 기준(원형 라벨), 아래쪽에 보고 구분]

- 막대(왼쪽→오른쪽): 근접오류 (LEVEL 0) | 무해사건(LEVEL 1) 경미한 위해사건(LEVEL 2) | 위해사건 (LEVEL 3) | 적신호사건 (LEVEL 4)
- 구분 기준(원형 라벨):
  - 근접오류와 무해사건 사이: 환자에게 적용여부
  - 경미한 위해사건과 위해사건 사이: 환자의 심각한 위해여부
  - 위해사건과 적신호사건 사이: 사망, 영구적 장애여부
- 보고 구분: LEVEL 0~2 쪽 = 자율보고 / LEVEL 3~4 쪽 = 의무보고
