## 조사항목/방법

| | 조사항목 |
|---|---|
| 1 | 퇴원 및 전원 절차가 있다 |
| 2 | 퇴원 결정과정에 환자가 참여한다 |
| 3 | 퇴원 전에 **퇴원요약지**를 작성한다 |
| 4 | **퇴원 시 필요한 정보를 제공한다** |
| 5 | 퇴원 시 **가정간호가 필요한 경우에는** 관련 정보를 제공한다 |
| 6 | **의뢰 및 전원서비스**를 제공한다 |

1. 조사위원이 질문
2. 관련자료 확인

- 퇴원요약지 확인 방법 : 조사당일 퇴원하는 환자의 의무기록 확인 가능 (퇴원기록 확인)
- 퇴원 시 정보 제공 : **퇴원간호기록, 퇴원약 복약 안내문 확인** (파란색 밑줄)
- 가정간호 정보제공 : 필요 시 담당의사가 가정간호 의뢰, 병동 내 가정간호안내문 통해 정보 제공
  (원내 가정전문간호사가 방문할 수 없는 지역인 경우 진료협력센터 의뢰)
- 전원 요청 시 : 의사가 의뢰서/회송서 작성 → BESTCare[전원의뢰] 통해 진료협력센터 의뢰 및 전원 요청

[그림: BESTCare 아이콘 화면캡처 — 집 모양과 사람 그림의 아이콘, 라벨 "가정간호의뢰"]

[그림: "가정간호 이용안내" 안내문 이미지. 항목 제목은 "소개", "내용", "방문지역" 이며, 본문은 해상도가 낮아 대부분 판독 어려움. 읽히는 범위:
- 소개: 가정전문간호사가 가정으로 방문하여 가정간호서비스를 제공하는 제도라는 취지의 설명 (세부 문구 [판독불가])
- 내용: 1)~7) 일곱 항목 (세부 문구 [판독불가])
- 방문지역: 1) 성남시 : 전체 / 2) 용인시 : [판독불가] / 3) 광주시 : [판독불가] / 마지막 줄 괄호 안 거리·시간 기준 문구 [판독불가]]
