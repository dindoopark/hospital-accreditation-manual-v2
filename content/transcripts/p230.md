■ 부 록

**1. 의료정보의 수집, 생성 및 활용 요청 절차**

[그림: 의료정보 수집·생성·활용 요청 절차 흐름도(스윔레인 도식). 슬라이드 왼쪽 절반에만 배치되어 있고 오른쪽 절반은 비어 있음. 도식 내 글자가 작고 해상도가 낮아 일부는 확대 판독 기준임]

스윔레인(열) 제목:

| 요청 부서 | SR 접수자(SM) | 자료처리 담당자 | 정보화실 |
|---|---|---|---|

주석(정보화실 열 우측 상단): *SR: Service Request, 요청서

흐름(도식 내 상자/마름모 문구):

1. (요청 부서) 요청서 작성 → 요청 부서 전자결재
2. (SR 접수자(SM)) 결재 문서 접수 → 자료 처리자 지정
3. (자료처리 담당자) 소요 일수 산정
4. (정보화실) [정보제공 담당자] 요청 목적 및 내용 확인 (개인정보 포함, 규정 적합 여부)
5. (정보화실) 판단 마름모 2개: "개인정보 포함" / "규정 적합"
   - 규정 적합 = N → (빨간 화살표) 요청 부서의 "반려"
   - 규정 적합 = Y → [팀장, 정보화실장] 전자결재 및 승인
   - 개인정보 포함 = N → (곡선 화살표) [팀장, 정보화실장] 전자결재 및 승인
   - 개인정보 포함 = Y → [정보제공 담당자] 전자결재 및 개인정보 보호 담당자에게 검토 요청 → [개인정보 보호 담당자] 검토 → 판단 마름모 "제공 가능 여부"
     - 제공 가능 여부 = N → (빨간 화살표) 요청 부서의 "반려"
     - 제공 가능 여부 = Y → [개인정보 보호 담당자] 전자결재 → [팀장, 정보화실장] 전자결재 및 승인
6. (SR 접수자(SM)) 요청서 접수
7. (자료처리 담당자) [자료처리 담당자] 자료 추출 문서 암호 설정 및 보안 문서 암호화
8. (자료처리 담당자) 판단 마름모 "개인정보 포함"
   - N → **원내 메일로 자료제공** (빨간 글씨) → (요청 부서) 자료 수령
   - Y → (정보화실) [정보제공 담당자] 개인정보 보호 담당자에게 최종 확인 요청 → [개인정보 보호담당자] 최종확인 → [정보제공 담당자] → **원내 메일로 자료제공** (빨간 글씨) → (요청 부서) 자료 수령
