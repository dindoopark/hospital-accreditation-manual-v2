## 6. 입원환자의 원내외 자살 시도 사고 발생 시 대처 절차

### 가. 원내 자살 시도 사고 발생 시 대처 절차

[그림: 원내 자살 시도 사고 대처 순서도 — 좌측 "진료부/간호본부 대처 및 보고 체계", 우측 "비상계획팀 대처 및 보고체계" 두 구역(점선으로 구분)]

**진료부/간호본부 대처 및 보고 체계**
1. 입원 병동 외 **공용구역**에서 사건 발생 및 확인
2. 발견자 보안반 신고 (T.1111) / CPR 방송(T.3000) → (비상계획팀) 보안반 접수
3. 사망 확정?
   - **예** → 현장보존 → 진료과 사후처치 및 관련 기록지 작성 (사망진단서 또는 시체검안서) → 부서 내 보고 (부서장 보고) → 1일 이내 원무팀 고객상담파트 구두 공유 → 진료부원장 보고
   - **아니오** → CPR 시행 → CPR 리더가 정하는 구역으로 이송 → 응급처치 시행 / 진료과 즉시 CPR 장소로 이동 / * 응급실로 이송된 경우 입원수진 기록/처방 → 사망?
     - **예** → 진료과 사후처치 및 관련 기록지 작성 (사망진단서 또는 시체검안서) 단계로 이동
     - **아니오** → 진료과 후속조치 후 입원부서 이송 (필요 시 전과/전동)

**비상계획팀 대처 및 보고체계**
1. 보안반 접수
2. 현장보존 및 접근 통제
3. 자살 사망 사고인 경우 경찰 신고
4. 필요 시 CCTV, 발견자 등 내용 파악하여 담당부서 통보, 경찰 수사 협조
5. 비상계획팀장 보고
6. 1일 이내 안전국장 보고

▣ 병동 내 사망한 상태로 발견된 경우 비상계획팀 보안반 신고(T.1111) 및 현장보존 필요

### 나. 원외 자살 시도 사고 발생 시 대처 절차

[그림: 원외 자살 시도 사고 대처 순서도]

1. 원외 자살시도 환자 119 통해 응급실 입실
2. 의식상태 및 신원 확인
   - **무명인** → 응급의학과 접수 → 응급의학과 응급처치 → 신원확인 → (입원 수진 환자 단계로 합류) / 신원확인 → (응급실행정파트) 무명인 기록/입원 기록 합본 요청
3. 입원 수진 환자 → 세 갈래로 분기

| 사망 | 응급상황 [심정지, 의식저하(GCS < 15), SBP< 90mmHg] | 응급상황 아닌 경우 |
|---|---|---|
| 응급실 내 수술장/CPR룸 입실 | (응급실간호파트) 응급의학과/입원부서 연락 / (입원부서) 진료과 연락 | (응급실간호파트) 입원부서 연락, 이송등록 / (입원부서) 진료과 연락 |
| (응급실간호파트) 입원부서 연락 / (입원부서) 진료과 연락 | 응급의학과 응급처치 / 진료과 즉시 응급실 방문 / * 입원수진으로 기록 및 처방 | 입원 부서 이송 |
| 진료과 시체 확인 퇴원 지시 및 관련 서류 작성 | 사망? — 예 → (좌측) 진료과 시체 확인 퇴원 지시 및 관련 서류 작성 / 아니오 → 진료과 후속조치 및 입원부서 이송 (필요 시 전과/전동) | |
| 입원 부서 퇴원수속 안내 | | |

▣ 입원 환자 원외 자살시도 발생 시 즉시 부서장 보고 → 1일 이내 원무팀 고객상담파트 구두 공유 → 진료부원장 보고

▣ 참고사항

(변사사건처리시행규칙 제12조1항) 원외 변사 사건 발생 시 변사 사건 책임자는 부검 고려 사건인 경우, 검시 전문 인력이 변사 사건 발생지에 나와 검시하도록 요청 이외 상황에서는 보호자가 외부 검안의를 요청하지 않는 경우 시체 확인을 위해 응급실 등 의료기관에 내원할 수 있음
