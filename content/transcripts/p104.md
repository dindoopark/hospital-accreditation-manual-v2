**부록 1. 소독제 희석 방법**

| 소독제 | 권장농도 | 희석방법 | 필요 보호구 | 비고 |
|---|---|---|---|---|
| 세니자임 | 1:100 | 물 1L + 세니자임 10cc / 물 100cc + 세니자임 1cc | 장갑 | * 매일 희석해서 사용 / * 하루에 필요한 양만큼 희석하고 남은 것은 폐기 (비고 칸은 전체 행 병합) |
| 락스 | 1:100 (500ppm) | 물 1L + 락스 10cc / 물 100cc + 락스 1cc | 장갑 | 〃 |
| 〃 | 1:50 (1,000ppm) | 물 1L + 락스 20cc | 장갑+마스크 (아래 행들과 병합) | 〃 |
| 〃 | 1:10 (5,000ppm) | 물 900cc + 락스 100cc | 〃 | 〃 |
| 바이오스팟 | 5,000ppm | 물 1L + 5 Tab / 물 200cc + 1 Tab | 〃 | 〃 |

단, 락스 원액을 다량 취급(많은 분량을 희석)하는 경우 장갑, 쉴드마스크(마스크+고글) 착용 필요

**부록 2. 환경관리 방법**

| 소독제 | 종류 | 관리 방법 | 비고 |
|---|---|---|---|
| 의료기기 (infusion pump, 모니터 등) | 1:100 세니자임 / 티슈형 소독제 | * 표면이 충분히 젖을 정도로 닦는다. | |
| 침상, 카트, 수술대, 처치대, 휠체어 등 | 1:100 세니자임 / 티슈형 소독제 | * 표면이 충분히 젖을 정도로 닦는다. | |
| 바닥 | 1:100 락스 / 1:100 세니자임 | * 진료공간: 1:100 락스 혹은 1:100 세니자임을 이용하여 표면이 충분히 젖을 정도로 닦는다. / * 진료공간 이외: 소독제 사용 불필요 | * 미끄럼 주의 |
| 화장실, 세면대, 샤워실 | 1:100 락스 | * 물때를 제거 후 1:100 락스를 이용하여 닦는다. | |

**부록 3. 특수 상황에 대한 환경관리 방법**

| 상황 | 환경관리 방법 |
|---|---|
| 혈액 및 체액이 쏟아졌을 때 | - 통기성이 없는 표면일 경우 500ppm 염소계 소독제를 이용하여 닦아냄. / - 유출된 양이 많거나(10mL 이상) 통기성 또는 흡수성이 있는 표면에 묻어 있는 경우 5,000ppm 염소계 소독제를 적신 걸레나 종이타월로 흡수한 후 500ppm 염소계 소독제를 이용하여 닦아냄. / - 높은 농도의 용액을 사용하더라도 바이러스가 비활성화 되지 않을 수 있기 때문에, 반드시 혈액과 같은 유기물질을 미리 제거해야 함. |
| *Clostridioides difficile* | - 5,000ppm 염소계 소독제를 이용하거나, 티슈형 소독제로 환경 소독 |
| 노로바이러스(Norovirus) | - 1,000ppm 염소계 소독제를 이용 (노로바이러스·로타바이러스 두 행 병합) / 우측 칸: (빈칸) |
| 로타바이러스(Rotavirus) | - 1,000ppm 염소계 소독제를 이용 (위와 병합) / 우측 칸: - 1:100 세니자임 / - 티슈형 소독제 |
| 결핵(Mycobacterium tuberculosis) | - 일반 환자와 동일 수준으로 환경관리 / - 단, 결핵균으로 오염된 표면은 1,000ppm 염소계 소독제를 이용 |
| 크로이츠펠트-야콥병(Creutzfeldt-Jakob Disease:CJD)과 새로운 변형 CJD(New variant CJD:nCJD) | - 중추신경계 조직 또는 뇌척수액 오염이 우려되는 경우 방수 커버 적용 / - 방수 커버 하지 않은 상태에서 고위험 조직에 오염되었을 경우, 흡수력 있는 물질로 오염을 제거한 후 10,000~20,000ppm 염소계 소독제를 이용 / - 감염위험성이 낮은 조직 및 체액으로 오염된 표면은 500ppm 또는 5,000ppm 염소계 소독제를 이용 |
| 다제내성균 | - 일반적인 1:100 세니자임 또는 티슈형 소독제로 환경관리 / - 접촉 전파 예방을 위해 병실을 포함한 오염된 표면을 세심하게 관리 |

● 원내 사용 가능한 염소계 소독제: 락스, 바이오스팟
