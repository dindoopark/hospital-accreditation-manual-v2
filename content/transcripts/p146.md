## (좌측) 부록 6. 근무를 제한하여야 하는 감염질환의 종류와 제한기간

근무제한의 기간, 정도 등은 유관부서와 주관부서에서 질환의 종류, 노출 정도 등을 고려하여 상황별로 정한다.

| 질 환 / 문 제 | 근 무 제 한 | 기 간 |
|---|---|---|
| **결막염** | 환자 및 환자 환경과 접촉 제한 | 분비물이 없어질 때까지 |
| **설사 질환** | | |
| 급성기 (다른 증상을 동반한 설사) | 환자 및 환자 환경과 접촉 제한<br>음식 취급 금지 | 증상이 없어질 때까지 |
| 회복기, 살모넬라증 | 고위험군 환자의 치료제한 | 증상이 없어지고, 대변검사 결과 음성일 때까지 |
| **디프테리아** | 근무 제한 | 항생제치료 완료 및 24시간 이상 간격의 2회 연속검사에서 음성일 때까지 |
| **Enterovirus 감염** | 신생아, 영유아, 면역저하환자 치료제한 및 환경접촉 제한 | 증상이 없어질 때까지 |
| **바이러스 간염** | | |
| A형 바이러스감염 | 환자 및 환자 환경과 접촉 제한<br>음식 취급 금지 | 황달 시작 7일 후 까지 |
| B형 바이러스감염 | | |
| HBsAg(+)인 급성 또는 만성간염이 있는 직원이 침습적 처치를 하지 않는 경우 | 역학적으로 감염전파와 관련이 있지 않은 한 제한하지 않음<br>항상 표준주의지침 준수 | |
| HBeAg(+)인 급성 또는 만성간염이 있는 직원이 침습적 처치를 하는 경우 | 노출발생 가능한 침습적 시술 수행 제한, 전문의(감염내과, 소화기내과)의 검토를 거쳐 결정 | HBeAg이 음성이 될 때까지 |
| C형 바이러스감염 | 권고안 없음<br>상황에 따라 검토 후 결정 | |
| **Herpes simplex** | | |
| 손(herpetic whitlow) | 환자 및 환자 환경과 접촉 제한 | 병변이 치료될 때까지 |
| 구강, 안면 | 고위험환자 직접 접촉 제한 | |
| **HIV 감염** | 항상 표준주의지침 준수,<br>노출발생 가능한 침습적 시술 수행 제한, 전문의(감염내과)의 검토를 거쳐 결정 | |
| **홍역** | | |
| 활동성 | 근무 제한 | 발진이 나타난 후 7일까지 |
| 노출 후(감수성 있는 직원) | 근무 제한 | 첫 노출 후 5일부터 마지막 노출 후 21일까지 혹은<br>발진이 나타나고 4일 후까지 |
| **수막구균 감염증** | 근무 제한 | 치료시작 후 24시간까지 |
| **유행성 이하선염** | | |
