**1. Braden Scale: 연령 12개월 초과**

| 구분 | 점수 | 점수 설명 |
|---|---|---|
| 감각기능 | 1점 | 의식저하나 Sedation으로 인해 통증자극에 반응없음. 혹은 신체 대부분에 통증감각이 제한되어 있음. |
| 감각기능 | 2점 | 신음이나 안절부절못하는 모습 외에 통증이나 불편감에 반응할 수 없음. 혹은 신체 1/2이상에 통증이나 불편감 인지에 제한적 감각장애가 있음. |
| 감각기능 | 3점 | 언어지시에 따를 수 있으나 불편감이나 돌아눕고 싶다는 의사표시가 어려움. |
| 감각기능 | 4점 | 언어지시에 따라 반응함. 통증이나 불편감에 관한 언어적 표현이나 감각인지의 장애 없음. |
| 피부습기 | 1점 | 땀이나 소변에 의해 항상 젖어 있음. 환자를 옮길 때마다 항상 피부가 축축함을 발견함. |
| 피부습기 | 2점 | 피부가 자주 젖어 있음. 근무 조마다 적어도 1회 이상 린넨교환이 필요함. |
| 피부습기 | 3점 | 하루 1회 린넨 교환이 필요함. |
| 피부습기 | 4점 | 피부가 대개 마른 상태이고 정기적 린넨 교환만으로 유지됨. |
| 활동상태 | 1점 | 계속적으로 침대에 누워있어야 함. |
| 활동상태 | 2점 | 보행능력이 없거나 매우 제한됨. 몸을 지탱할 수 없거나 의자나 휠체어로 옮길 때 도움 필요함. |
| 활동상태 | 3점 | 낮 동안 때때로 걸으나 짧은 거리만 가능함. 대부분을 의자나 침대에서 보냄. |
| 활동상태 | 4점 | 적어도 하루에 두번 정도는 산책할 수 있음. |
| 움직임 | 1점 | 도움 없이 몸이나 사지를 전혀 움직이지 못함. |
| 움직임 | 2점 | 신체나 사지의 자세를 약간 바꿀 수 있으나 잦은 자세변경이나 완전한 자세변경을 스스로 할 수 없음. |
| 움직임 | 3점 | 독자적으로 자주 약간의 자세변경을 할 수 있음. |
| 움직임 | 4점 | 자세변경에 있어 도움 없이 자주 돌아누울 수 있음. |
| 영양섭취 | 1점 | 제공된 음식의 1/3 이상을 먹지 못함. 혹은 금식으로 5일 이상 정맥주입을 유지함. |
| 영양섭취 | 2점 | 제공된 음식의 1/2 정도를 먹음. 혹은 유동식이나 경관 유동식을 섭취함. |
| 영양섭취 | 3점 | 대부분 반 이상을 먹음. 혹은 경관 유동식, TPN을 주입함. |
| 영양섭취 | 4점 | 거의 다 먹음. |
| 피부마찰과 전단력 | 1점 | 움직이는데 도움이 필요함. 홑이불에 쓸리지 않고 환자 들기가 불가능함. 자주 침대나 의자에서 밀려 내려가고 자세를 바꾸는데 많은 도움이 필요함. 경련, 경직 등에 의해 계속적인 마찰이 생김. |
| 피부마찰과 전단력 | 2점 | 힘들게 움직이고 약간의 보조가 필요함. 움직일 때 린넨, 의자, 억제대에 피부가 쓸리게 됨. 대부분 의자나 침대에서 좋은 자세를 유지하나 가끔 밀려 내려 감. |
| 피부마찰과 전단력 | 3점 | 침대나 의자에서 혼자 움직이고 홑이불에 쓸리지 않을 만큼 충분히 자신이 지지함. |

**3. 욕창 분류 기준**

| 욕창단계 | 점수 설명 |
|---|---|
| Stage 1 | 비창백성 홍반(non blanching erythema)으로 일반적으로 뼈 돌출부위에 국소적으로 형성되며, 눌러도 하얗게 되지 않는 발적이 있는 손상이 없는 피부 상태를 나타냄 |
| Stage 2 | 표피는 물론 진피가 부분적으로 손상된 상태로 분홍색이나 붉은색을 띠며 부육(slough)조직이 없는 얕은 궤양으로 장액성 수포가 나타나기도 함. |
| Stage 3 | 표피와 진피는 물론 피하조직까지 손상된 상태로 피하조직은 관찰되나 근육, 건, 뼈는 노출되지 않은 상태, 괴사조직이나 잠식과 동로(sinus tract)가 존재할 수 있음. |
| Stage 4 | 뼈, 인대, 근육이 노출된 전층 피부 손상으로 부육(slough)조직과 건조 가피가 일부 나타날 수 있으며, 잠식과 동로(sinus tract)가 존재할 수 있음 |
| Deep Tissue Injury (DTI) | 손상되지 않은 피부에 자주색 또는 적갈색의 국소적인 피부색 변화가 있거나 혈액이 찬 수포가 있음. 주위 조직에 비해 통증이 있고 단단할 수 있음 |
| Unstageable | 욕창의 기저부가 부육(slough)조직 또는 건조가피로 덮여 있는 전층 피부 손상으로 손상된 조직의 깊이가 불명확함 |

**4. 욕창 관리 절차 모식도**

[그림: 욕창 관리 절차 흐름도]
- 욕창평가
  - **욕창이 없는 경우** → 욕창위험도 평가
    - **위험군** → 욕창 예방활동 / 욕창위험도 재평가 시행 → 예방활동 결과 확인
    - **비위험군** → 정기적 욕창위험도 재평가 시행
    - (위험군 상자 ↔ 비위험군 상자 양방향 화살표)
  - **욕창이 있는 경우** → 욕창기록 작성
    - Stage 1, 2 → 수간호사, 상처전문간호사 보고
    - Stage 3, 4 / DTI, Unstageable → 수간호사, 상처전문간호사, 주치의 보고 / 필요시 성형외과 협진 (전문적 평가 및 관리)
    - (두 분기 모두) → 욕창 관리 활동
