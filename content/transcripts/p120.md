## 음압병실 모니터링 기록지(전실 無)

장소 : ________________

※ 격리환자 입실 전, 격리환자 재실 중 매일 한번씩 차압 작동/유지 여부를 확인하여 체크하여 주시기 바랍니다.
   **(격리환자가 재실하지 않은 경우에는 1회/월 체크)**
※ 점검방법 : 병실 문이 닫혀 있는지 확인 후, 병실 앞에 있는 압력 조절판을 보고, 수치 및 정상 범위를 확인한다.
※ 목표값: ≤-2.5Pa (≤-0.25mmAq)

| 날짜 (년/월/일) | 격리환자 입실유무(√) — 격리시작 | 격리환자 입실유무(√) — 격리 중 | 격리환자 입실유무(√) — 격리 미시행 | 차압(단위:______) 병실-복도 | Pass/Fail (o/x) | 확인자 | 비고 (조치사항/해결여부) |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

(이하 빈 행 반복)

•장소: 해당 실방명 기록, •날짜: 점검 사유가 발생한 날짜, •격리환자 입실유무(격리시작/격리중/격리 미시행): 해당 부분에 체크,
•차압: 압력 조절판의 수치 기록, •Pass/Fail: 목표차압을 달성한 경우 o, 달성하지 못한 경우 x
•확인자: 점검을 수행한 자, •비고: 적절 차압이 유지되지 않아 조치를 수행한 경우 내용, 조치결과 기록

시설팀 ☎ 1600~3, 감염관리팀 ☎ 3900~4, 1370~3 (※ 글자가 작아 번호 일부 판독 불확실)
