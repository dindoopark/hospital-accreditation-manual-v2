# p052 | 3.6 욕창예방관리
- kind: content

## 조사항목/방법

| | 조사항목 |
|---|---|
| 1 | 욕창 예방관리에 대한 규정이 있다. |
| 2 | 욕창 위험 평가도구를 이용하여 환자 입원 시 초기평가를 수행한다. |
| 3 | 욕창 위험 평가결과에 따라 고위험환자에 대한 욕창 예방활동을 수행한다. |
| 4 | 욕창 위험 평가도구를 이용하여 정기적인 재평가를 수행한다. |
| 5 | 욕창이 발생한 환자에게 욕창 관리활동을 수행한다. |

1. 조사위원이 질문
2. 의무기록 확인

| | 12개월 초과 | 12개월 이하 |
|---|---|---|
| 평가도구 | Braden Scale | Neonatal / Infant Braden Q |
| 위험군 기준 | 6~18점 이하 | 8~19점 이하 |
| 초기평가 | 입원 시 (24시간 이내) 평가 (두 열 공통) | |
| 재평가 주기 | 일반 병동: 주 2회 (매주 수요일, 일요일) / 중환자실: 매일 (Daily) (두 열 공통) | |
